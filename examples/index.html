编辑器 A：默认工具栏（含 Markdown 模式按钮）

① 斜杠菜单：空行输入 / 或点行首 +（Markdown 模式源码栏）；空段落输入 /（富文本）。支持拼音过滤（bt / h2 / bg / gs / code）。
② 分栏模式：点 Markdown模式 → 左源码右预览（预览可直接编辑）；模式栏切换 源码/分栏/预览；工具栏按钮对激活栏生效：源码栏选中文字后点颜色/对齐/字号，看源码变化；插图/视频在源码栏会转 Markdown 插入。
③ 快捷键：Ctrl+B/I/U、Ctrl+K（链接）、Ctrl+Shift+C（代码块）、Ctrl+Shift+M（公式）；列表回车续写、空项回车结束、Tab 缩进。
④ 代码块：光标进代码块右上角浮出工具条（语言/主题/应用到全部/复制）；编辑器内代码按主题着色。
⑤ 公式：工具栏公式按钮 → 本地 KaTeX 对话框（模板/预览/行内块级）；双击公式编辑；$x^2$ 闭合自动转换。
⑥ 退出：预览区改过的内容零损失；源码栏改过的部分经 Markdown 渲染。
